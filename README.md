# Light Shader

A lightweight Minecraft Bedrock shader focused on atmospheric lighting, water, skies, caves, and mobile performance.

## Requirements

- Minecraft Bedrock Edition
- MB Loader
- Android device

## Installation

1. Install MB Loader.
2. Import the `Light Shader.mcpack` file into Minecraft.
3. Activate the resource pack.
4. Launch Minecraft through MB Loader.
5. Load your world and enjoy.

## Testing

Light Shader was tested on a Realme 5 running Android 10 with a Snapdragon 665.

Performance may vary depending on the device, GPU, RAM, Minecraft version, render distance, thermal conditions, and background applications.

## Features

- Atmospheric lighting
- Improved water visuals
- Sky and sunset effects
- Night sky effects
- Cave lighting
- Lava illumination
- Mobile-focused optimization
